How a store page works

Every club page has 3 parts stacked from top to bottom. You never have to build or update a product grid by hand.

Quick guide: how to change anything

What you want to changeWhere to goTimeHow it works
Add, remove, or change a product Club Contract / DX tool Automatic Gabby updates the club contract, or DX updates the product widget. The page updates itself with zero HTML changes.
Swap one photo or link right now Fastr Editor (links in Tab 5) 10 seconds Open the club's Fastr block, paste the new https://... photo link over the old one, and click Save.
Update photos or links across stores Airtable: Pop-up Store Product Same day Change the link in Airtable (tblNWQqlb5AMoyQoM). We regenerate the store code straight from Airtable.

How to swap a photo in Fastr (10 seconds)

  1. Click Edit in Fastr (on Tab 1 or Tab 5).
  2. Find the old https://... image link in the code box.
  3. Paste the new image link in its place and click Save.

How to change a product in the grid (no code)

  1. The product grid is a standard Soccer.com contract widget.
  2. Update the club's TPS contract or edit the widget in DX.
  3. The store page updates automatically. Nothing to copy or paste.

1. Fastr previews and code editor

Every store or block has two buttons:

Open Preview
Opens the test page in your browser so you can look at the design and test the links.
Edit in Fastr
Opens the Fastr code box where you paste new HTML or swap a photo link.
Two quick tips when editing in Fastr: Only one person should edit a block at a time (two people saving at once will overwrite each other). After you click Save, check the page in a private browser window if you still see the old version.
