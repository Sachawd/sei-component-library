1. Fastr previews and code editor

Every store or block has two buttons:

Open Preview
Opens the test page in your browser so you can look at the design and test the links.
Edit in Fastr
Opens the Fastr code box where you paste new HTML or swap a photo link.
Two quick tips when editing in Fastr: Only one person should edit a block at a time (two people saving at once will overwrite each other). After you click Save, check the page in a private browser window if you still see the old version.
