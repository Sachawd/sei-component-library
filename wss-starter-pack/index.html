04 · Your AI Agent Setup Copy & Paste into Claude or Cursor

3. The "Forget Old Rules" AI prompt.

Alex asked on the call: "Can I just give my agent the new rules and tell it to forget everything from before?" Yes. Paste this exact block at the start of your chat, along with your starting HTML file from the Code Library.

1-Click Copy: Master Reset & Build Prompt for WorldSoccerShop Designers 
Forget all previous instructions and older Fastr or Composer rules. Follow only this updated WorldSoccerShop Fastr CMS workflow:

1. STARTING CODE (NEVER START FROM SCRATCH):
- Start strictly from the attached reference HTML file from the Sports Endeavors Marketing Code Library (https://sachawd.github.io/sei-component-library/).
- Keep the layout engine, class names, and structure intact. Change only the content (text, links, and image filenames) to match my Figma frame and Figma annotations.

2. CSS SHIELD & SCOPING (PREVENT STOREFRONT FONT/COLOR BUGS):
- Fastr injects HTML directly into the WorldSoccerShop page with no iframe sandbox.
- Never style html, body, :root, or bare *, and never use vh/100vh units.
- Prefix every CSS rule with the component's doubled root ID selector (#root-id#root-id) and include the doubled-ID :where(...) reset so legacy store CSS cannot override fonts, link hover states, or inputs. Use explicit px font sizes instead of rem.

3. LINKS, PRODUCTS & PROMO CODES:
- Every destination URL must come from the WorldSoccerShop Link Book (SITE-LINKS in Box). If a URL is missing from the Link Book, write "Unknown" and ask me so we can add it the same day. Never invent or guess a URL.
- Every link must include target="_top" and carry no internal ?utm_ parameters.
- Products come from the requester's CSV or Tunnel Product picks link. Never invent SKUs or prices.
- Test pages are public: use PROMO-CODE-HERE for any unreleased promo code until the cart test passes.

4. IMAGES & SPEED (NO LAZY LOADING):
- Every image loads eagerly (never use loading="lazy") and carries explicit width and height attributes.
- Mark only the very first hero image fetchpriority="high" (one per block, never more).
- Bucket photos on https://www.imagehandler.net/dxassets/?img=Photos/ ignore width parameters, so wire --w480.jpg and --w960.jpg responsive copies using srcset and sizes (with a self-disarming onerror fallback that strips srcset first). Upload JPG only (300 KB max for desktop heroes, under 200 KB for all other photos, never WebP, and encode + as %2B).

5. ADA ACCESSIBILITY & SEO:
- Check contrast before finishing: body text must be at least 4.5:1, large text and buttons at least 3:1. Tell me immediately if any color pair in my design fails ADA contrast.
- Include descriptive alt text on content images, empty alt="" on decorative images, 24px minimum tap targets, visible keyboard focus, and prefers-reduced-motion support.

6. OUTPUT & RESERVED HEIGHTS (NO LAYOUT SHIFT):
- Before coding, write a 5-line "Done means" checklist in plain words.
- Output the complete, unbroken HTML file from the first line to the closing tag (never truncate with "rest of code" comments, and include zero Figma node numbers or working comments).
- Give me the 3 measured pixel heights in order at the top of the file: Mobile (390px wide), Tablet (640px and up), and Desktop (1024px and up) so I can enter them into Fastr's Reserved Height boxes and use the "Reserves space" embed tab.

7. PILOT FEEDBACK LOG FOR SACHA:
- If any instruction, asset, or step in this build is unclear or causes an issue, write a short Markdown summary titled "Process Feedback for Sacha" at the end of our session so I can send it to her.
Figma Annotations Tip from Friday's Call:
In Figma, use the Annotate tool (instead of regular comments) to tag frames with notes like "use placeholder date", "swap to Premier League clubs", or "link to /shop/clubs/arsenal". AI agents read Figma annotations directly from the frame.

Always open the saved HTML file in Visual Studio Code, Cursor, Antigravity IDE, or Dreamweaver to copy it (never copy code directly out of a chat window).

05 · First Practice Run 6 Steps from Figma to ClickUp

4. Your 6-step checklist for Pilot #1.

Use this single page as your cheat sheet while running your first practice build.

Steps 1 & 2 · Prep

Task & Figma Frame

  • 1. Log in Site Change Requests Make sure the task is in the ClickUp Site Change Requests list (never work from a raw Teams or Slack message).
  • 2. Build with Auto Layout in Figma Pull the component from Cabana 8 (Code Blocks → Builders) into the WSS Site Updates Figma file, set Auto Layout, and add any Figma Annotations.
  • 3. Prep photos in Tunnel & Photo Sizer Pick existing photos in Tunnel V2, or crop new JPGs in Photo Sizer (300 KB hero / 200 KB rest, plus 480 and 960 copies) for Sacha or Anthony to upload to S3.
Steps 3 & 4 · Code & Paste

AI Build & Fastr Test Page

  • 4. Run the Master AI Prompt Give Claude your starting HTML file from the Code Library, the Master Prompt from Page 4, your Link Book URLs, and your Figma frame.
  • 5. Browser check, then Code Editor copy Open the HTML file in Safari/Chrome on your Mac first to confirm every photo shows. Then open it in VS Code, Cursor, or Dreamweaver, press Command+A and Command+C.
  • 6. Paste into Fastr & "Reserves space" Paste into your Fastr component (Brand: WorldSoccerShop), enter the 3 Reserved Heights (390 / 640+ / 1024+), click Save, and place the Reserves space embed on your test page.
Steps 5 & 6 · Test & Share

PageSpeed, Jam & Code Share

  • 7. Check a second browser if cached If Fastr shows your old version after clicking Save, open the test page URL in a second browser (like Safari) before re-pasting.
  • 8. Run PageSpeed & record 1 Jam Test the preview URL in PageSpeed Insights and record a quick desktop + mobile Jam video (checking that store fonts did not override your block).
  • 9. Create 1 Code Share link for ClickUp Paste your HTML into Code Share (the-tunnel.netlify.app/code-share/), copy the share link into the ClickUp task's HTML Code row, and send Sacha any process notes.
Need help or hit a wall?
Do not spin your wheels. If a component is missing in Figma, a photo needs uploading to the S3 bucket, or an AI tier cuts off a file, message Sacha on Teams or text her right away.
