How The Tunnel v3 Works

Complete technical reference covering the 26 October 2026 Tunnel v3 rebuild (Nutmeg shell, 5 brand views, Holiday 2026 separation, Osmo GSAP Flip photo viewer, CSV selection bar, and AES-256-GCM Superside partner page) alongside the ClickUp, 2026 Box, S3 ImageHandler, and Daily Product Feed pipelines.

Last updated: 27 October 2026
Scope: Soccer.com, WorldSoccerShop, 431 Sports, Team.Soccer.com, Vendor Packs
Status: Production (Tunnel v3 Live)

1. System Overview

The Tunnel v3 is Sports Endeavors' internal search engine and creative asset library for Soccer.com, WorldSoccerShop, 431 Sports, Team.Soccer.com, and Vendor Packs. Instead of hunting across ClickUp tasks, Box folders, and email threads, the team searches once by club, player, boot, brand, campaign, or SKU.

Key Architecture Principle: Static App + Two Asset Lanes
The Tunnel v3 runs as a zero-backend static web application (SEI-COMPONENT-LIBRARY/tunnel/) backed by per-brand JSON indexes (data/*.json) and 918 per-shoot manifests (files/*.json). It uses Lane A (Amazon S3 ImageHandler) for web-sized campaign photos that open inside the Osmo GSAP photo viewer, and Lane B (Direct Box & Vimeo Links) for large 2026 Box shoot folders and studio videos.

5. Superside External Partner View (AES-256-GCM Gate)

Because GitHub Pages is a static host with no server-side login, the external Superside partner page (holiday-2026-partner.html) uses authenticated client-side encryption via the browser's native Web Crypto API (window.crypto.subtle):

  • Zero plaintext in source: Neither holiday-2026-partner.html nor any unencrypted script on that page contains shoot titles, S3 URLs, Box links, or SKUs.
  • Key derivation (PBKDF2): When a user enters the password, the browser derives a 256-bit key using PBKDF2-HMAC-SHA256 with 210,000 iterations and a random 16-byte salt stored in data/partner-holiday-2026.enc.json.
  • Authenticated decryption (AES-256-GCM): The derived key decrypts the ciphertext payload in memory and renders the 35 Holiday 2026 shoots (16 Danny shoots + 19 Orbitvu shoots) with search, category filters, S3 photo drawers, Vimeo 360 links, and CSV export.
  • Session persistence: Once unlocked, the session stays active in sessionStorage until the tab closes or the user clicks Lock.

6. Why The Tunnel Uses Two Asset Lanes (S3 vs. Box)

Here is how the two asset lanes keep The Tunnel fast without duplicating 103,740 Box files:

Topic Lane A: Amazon S3 ImageHandler Lane B: Direct 2026 Box & Vimeo Links
What goes here Website campaign shoots (such as the 320 Holiday 2026 JPGs and Chivas shoots), vendor launch packs, and 256 PNG logos. Large 2026 Box shoot folders (71 active folders inside the 368-folder WSS Marketing Box tree) and studio videos / Vimeo 360 spins.
How files are served Served publicly via imagehandler.net/dxassets/?img=Photos/<filename>. Point instead of copy: Raw files stay in Box or Vimeo; the card links straight to the live shared URL.
Experience in Tunnel v3 Clicking View shoot opens individual photo cards, the Osmo GSAP Flip dark viewer, 1-click download, and multi-photo CSV export. Clicking Open in Box or Watch 360 Spin opens the live Box folder or Vimeo video immediately.

7. Team Upload Workflow (For Tyler, Alex, Taj & Merch)

Follow this three-step workflow whenever you upload a new pack shoot or video so it flows cleanly into The Tunnel:

1

Upload into a 2026 Box Folder

Place the shoot or video inside the appropriate 2026 folder in WSS Marketing Box so our 2026 folder scanner includes it.

2

Copy the Shared Box Link

In Box, copy the Shared Link for that folder (set access to people in your company or people with the link).

3

Paste the Box Link on the ClickUp Launch Task

Paste that Shared Box Link into the ClickUp task description or comments. Our daily Tunnel sweep reads the ClickUp tasks and 2026 Box folders and adds the card to The Tunnel.

9. Dev & IT Handover Summary (Anthony & Anil)

The Tunnel v3 is a static web application with zero database servers to maintain. The handover to Dev/IT is strictly to run two scheduled daily jobs off Sacha's laptop:

Scheduled Job Cadence What It Reads & Outputs
Job 1: Daily Reflektion Feed Pull Daily (every morning) Pulls the daily WSS, SDC, and 431 TSV product feeds (keeping stores separate) to refresh live prices, stock by size, and Player RV jerseys.
Job 2: Daily ClickUp + 2026 Box Sweep Daily (only rebuilds when new shoots appear) Reads ClickUp Launch lists (901109248850, 901112708469) and the 71 active 2026 Box folders via a read-only Box Custom App, appends any new shoot cards to data/*.json and files/*.json, and deploys when new assets are found.
