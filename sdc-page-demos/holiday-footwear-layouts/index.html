Soccer.com Holiday 2026 footwear page: who builds which band

Desktop and mobile, top to bottom. Blue bands are Fastr blocks built by Creative. Striped bands are native DX / Reflektion product widgets placed by the DX team between the Fastr blocks.

Drawn from the live page demo at sdc-page-demos.netlify.app/holiday-footwear, Mon 26 Oct 2026. Rule locked Fri 16 Oct 2026.

  • 0Product tiles rendered by Fastr code. No prices, no stock, no add to cart.
  • 8Fastr blocks: heroes, stories and category links only.
  • 2Native DX / Reflektion widget slots for the real product carousels and grids.

For Jordan's team

  • Fastr blocks never render product tiles, prices or stock. If a band needs real products, it is a DX widget slot.
  • The page is a sandwich: Fastr block, DX widget, Fastr block. A widget cannot sit inside a Fastr block, so the old tabbed product rails became one header block plus one widget slot.
  • The three pills in the 30% off header link straight to category pages. If one widget per tab is wanted instead, that is three widget slots stacked under the header.
  • The live demo marks both widget slots with a striped box and the words "Native DX / Reflektion product widget".
