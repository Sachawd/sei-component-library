Standards

Designer & Builder Rules

Three rules that keep every Fastr CMS block fast, sharp, and accessible on both stores.

Back to Components Open Photo Sizer
1 Bucket Rule

Export Real JPGs Only

  • Our image server only renders JPG files uploaded to the S3 Photos bucket.
  • Main hero backgrounds must stay at or under 300 KB, and all other photo slots at or under 200 KB.
  • Never use spaces, plus signs, hashtags, or ampersands in file names.
Use Photo Sizer
2 Live HTML Text

Keep Copy Out of the Photo

  • Headlines, promo pills, subcopy, and buttons are built as live HTML text over clean photography.
  • Never export an animated GIF of words or bake headlines into the background JPG.
  • The block code handles the entrance motion and contrast scrim automatically.
See Live Example
3 Fastr CMS

Use Reserves Space Heights

  • Enter the three measured pixel heights for Mobile, 640px, and 1024px in the Fastr Dashboard.
  • Always copy the embed code from the Reserves space tab so the page does not jump while loading.
  • WorldSoccerShop and Soccer.com never mix product links or feeds.
