Zeta checklist

1. Images

S3 or Imagehandler

  • Host email GIFs, PNGs, and JPGs on S3 so Brock skips uploading to Zeta.
  • Or type an article number in the editor to pull a product cutout from Imagehandler.
  • Check the visible Alt Text box so blocked images still read cleanly in Outlook.
2. Tracking

Zeta & Google Analytics

  • Zeta automatically wraps every link in its own click-tracking redirect at send time.
  • Enter the Campaign Name in the editor to append utm_campaign and utm_content automatically.
3. Paste

Drop into Zeta HTML block

  • Click Copy code above after making your text, colour, image, and link edits.
  • Paste into a Zeta HTML block and send a test to Outlook and Gmail.
