Sale category tiles

Four big photo tiles: Jerseys, Player kits, Apparel, Footwear.

Live demo

Switch the screen width. Photos show only once they are on the image host.

Open in a new tab

How it's built

Four big photo tiles: Jerseys, Player kits, Apparel, Footwear. A panel of quick links slides up on hover and stays open on phones.

Notes from the code

  • Look comes from the campaign tokens at the top of the style block.

Fastr heights

Type these into the three Reserved height boxes.

2552pixels on phones (Mobile box).
1280pixels from 640 wide.
1624pixels from 1024 wide.

The code

Paste the whole file into one Fastr HTML component.
