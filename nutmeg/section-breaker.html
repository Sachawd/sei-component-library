Section Breaker

A headline band between carousels: stars, eyebrow, headline, copy, then a button, filter pills or a link.

Live demo

Switch the screen width. Photos show only once they are on the image host.

Open in a new tab

How it's built

A headline band between carousels: stars, eyebrow, headline, copy, then a button, filter pills or a link. Can be pasted many times on one page.

Notes from the code

  • Change the look with the three settings on the <section> line:
  • data-align = center | left | right | split (split: words on the left, action on the right from 1024px up)
  • data-action = button | pills | link | none (pills: a row of filter links; add aria-current="page" to the one that is on)
  • data-theme = light | dark
  • Delete the stars, eyebrow or copy line if a breaker does not need them.
  • Give each pasted copy its own title id (sbk-1-title, sbk-2-title...).

Fastr heights

No single set of heights.

This block's height changes with its settings or its content. Measure it for each use. The notes from the code say why.

Accessibility

Contrast measured when the block was built.

  • Black on white 21:1 pass.
  • Button words on black 17.4:1 pass.
  • Pill text 14.9:1 pass.
  • Pill edge 3.05:1 pass (needs 3:1).
  • Dark: yellow on night 14.3:1 pass.
  • White on night 18.9:1 pass.
  • Black on yellow button 15.9:1 pass.
