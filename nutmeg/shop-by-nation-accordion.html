Shop by Nation accordion

Nation photo panels that widen on hover. On phones they become a swipe rail. No JavaScript.

Live demo

Switch the screen width. Photos show only once they are on the image host.

Open in a new tab

Before designers use it

This block needs a review before it goes on a page.

It was copied into the library on 25 Oct 2026 from the canon folder, as it was. Fable and Sacha still need to check it against the paste rules, the five screen widths and contrast. Until then, study it and build from it, but check with Sacha before using it.

  ════════════════════════════════════════════════════════════════════════════
  SHOP BY NATION — hover-expand accordion · Soccer.com · v3 · 2026-09-17
  ──────────────────────────────────────────────────────────────────────────
  v3 adds photography to v2. Everything else is unchanged from v2.

  Surface: Fastr CMS HTML widget. Native component, NOT an iframe.
  Fragment, not a document: no doctype, html, head or body. v1 had none either.
  Zero JavaScript. The component is complete with no script.

  HEIGHT BUDGET (exact heights, never min-height)
    ≤ 767px    480px   swipe rail, one panel visible + peek
    768–1023px 560px   flush accordion
    ≥ 1024px   620px   flush accordion

  TOKEN CHECK — every name verified 2026-09-17 against the production
  components that ship today, the Friends & Family sale page and the Matchday
  Bar Finder.
    --theme-text-body ............ exists in production ... kept
    --theme-bg-page .............. exists in production ... kept
    --theme-text-oninvert ........ exists in production ... kept
    --theme-bg-subtle ............ exists in production ... kept
    --theme-bg-primary-normal .... exists in production ... kept
    --font-body .................. DOES NOT EXIST ......... removed
  There is no production font token. Both reference components declare their
  own local font variable and put the real stack in it, so this one does the
  same with --sdc-ta-font. Typography ships as utility classes, not tokens.
  No name here can have its fallback win silently.

  IMAGES — all five real. Chosen from the Tunnel build on the Mac
  (CLICKUP-ASSET-SWEEP/the-tunnel, 8,313 items, read 2026-09-17). Addresses are
  built from the file name: the dxassets image host, plus Photos/ and the file
  name, with + # & encoded. Vendor Assets is the shared tier and is usable on
  Soccer.com. No WorldSoccerShop asset is used anywhere here.

  RIGHTS: everything in the Tunnel is approved for photography use
  (Sacha, 2026-09-17). Named players need no separate check, so frames were
  picked on quality rather than on avoiding a face.

    Germany ..... 3:4  Florian Wirtz, 26/27 away player frame
    England ..... 3:4  Cole Palmer, 2026 player frame
    Peru ........ 3:4  federation 2D, the only portrait Peru frame in the Tunnel
    Scotland .... 3:4  federation 2D, the only portrait Scotland frame in the Tunnel
    Mexico ...... 3:4  26/27 away, fans

  TWO NATIONS CHANGED, and why. Wales and South Africa have no Soccer.com-usable
  photography at all: Wales has one Vendor Assets item and it is a thumbnail,
  and all seven South Africa items are tagged WorldSoccerShop. Rather than ship
  two grey panels, England and Mexico take their places. Both are live on
  Soccer.com and both have deep coverage in the Tunnel. Swap them for any other
  nation freely; the only requirement is a live team page and a portrait frame.

  VERTICAL ONLY (Sacha, 2026-09-17). Panels take portrait frames only:
  3:4, 4:5, 2:3 or 9:16. Never square, never landscape. A 1:1 or 16:9 frame
  centre-crops to a strip of itself in a panel this tall and loses the kit.
  When swapping a nation, check the frame's ratio before the filename.

  CROP: every frame is 3:4. The panel is 1 to 1.375 and a 3:4 frame is 1 to
  1.333, so a sliver comes off the bottom of each. The crop is anchored top, so
  faces and kit stay safe. Nothing here is 16:9.

  NOT ONE OF THESE FIVE HAS BEEN SEEN TO RENDER. No agent call was made to the
  bucket or the image host, per Sacha's standing rule of 2026-08-27 that the
  check is a human in a real browser. Open each one before this ships.

  LINKS — all five click-verified on the live site 2026-09-17. Every one
  returns 200. The link book's slugs each redirect one hop to a
  "-national-team" address, so the canonical addresses are used here and the
  redirect is skipped.
  Two corrections to the link book worth making in Airtable:
    South Africa IS live, at /shop/fan/teams/south-africa-national-team.
      It is missing from site-links.csv. It is restored to this component.
    Northern Ireland is genuinely not on Soccer.com. Both plausible addresses
      return 404. Wales stands in its place. Nothing was invented.

  CONTRAST — measured, worst case (a pure-white photograph behind the scrim)
    Team name, white on scrim ........ 9.6:1  PASS
    CTA ink on CTA ground ........... 14.9:1  PASS
    Section title on page ........... 14.9:1  PASS
    Focus ring, white on scrim ....... 8.5:1  PASS (3:1 needed)

  PRE-FLIGHT GREP: clean. No html, body, :root, bare * reset or 100vh selectors.
    The string "body" appears only in the token name --theme-text-body and in
    this comment. That is a false positive, not a document-level rule.

  ⚠️ DEVIATION 1 — cta-canon.css declares its Osmo API on :root. A CMS widget may
     not target the root, so the same declarations sit on the wrapper class.
  ⚠️ DEVIATION 2 — every Osmo .button-009 selector is prefixed with the wrapper
     class. Declarations, easings, hover calc, click scale and focus ring verbatim.
  ⚠️ DEVIATION 3 — the label face is Figtree, not Chakra Petch. Figtree is
     Soccer.com's font; Chakra Petch is WorldSoccerShop's.
  ⚠️ DEVIATION 4 — CTA ground and ink reference --theme-* tokens rather than the
     canon's literal #fff/#0A0A0A, per the CMS token rule.

  NO CLICK BEACON. The beacon exists to cross an iframe boundary. This renders
  natively on soccer.com, so its links are ordinary internal navigation and
  analytics already sees them.

  CHANGED IN v2
    1. Phone rail allows vertical page scroll with a thumb on the rail.
    2. --font-body removed, see the token check above.
    3. Images: three real frames in, two nations still grey. See above.
    4. No doctype to remove; v1 was already a fragment.
    5. --sdc-ta-* renamed --sdc-ta-*. The campaign layer stays for campaign
       colour and type only.
    6. Links click-verified and switched to the canonical addresses.
       South Africa restored in place of Nigeria.
