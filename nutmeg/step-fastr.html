08 - Fastr CMS

Checking in Safari, copying from VS Code into Fastr with the 3 heights, and using Reserves space.

Never copy code from a chat window or click the chat Download button.

Chat windows cut long files off and turn straight quotes into curly quotes. Always open the saved FINAL file from your Mac's Downloads folder in a code editor.

OrderActionDetail
1. Find the FINAL fileOpen your Mac's Downloads folder.Find the single file named <page>--FINAL--<date>-<time>.html (for example wss-sale-page--FINAL--2026-10-20-1035.html). Only a file that passed Fable's check carries FINAL.
2. Check photos in a browserRight-click the FINAL file and open with Safari or Chrome.Scroll top to bottom and confirm every photo loads. If any photo is blank or broken, stop and tell the agent before pasting into Fastr.
3. Open in a code editorOpen the FINAL file in Visual Studio Code, Cursor, Antigravity IDE, BBEdit, or plain-text TextEdit.Never open code in Word, Pages, Notes, rich-text TextEdit, a browser, or Figma.
4. Select all and copyClick inside the code window, press Command A, check the last line, and press Command C.Scroll to the bottom first to confirm the closing tag the agent named in chat is highlighted.
5. Paste into FastrIn your Fastr HTML widget, click in the code box, press Command A, Delete, Command V, and click Save.Clear all old code before pasting your new code.
6. Check a second browserOpen your Fastr test page URL in a second browser if needed.Fastr's cache can keep showing the old version in the browser where you clicked Save (verified 9 Sept 2026). Check Safari if you saved in Chrome before re-pasting.
