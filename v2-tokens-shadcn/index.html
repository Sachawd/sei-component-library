01 · Design System V2 & Vue 3 Architecture 23 Oct 2026 · Design & Frontend Engineering

Vue 3 + shadcn-vue + V2 Tokens

Once Frontend reaches Vue 3, pairing shadcn-vue (Reka UI) with our 68-role V2 token set gives Soccer.com, WorldSoccerShop, and 431 Sports accessible components out of the box without building twice.

1 · The V1 Lesson

Sequence the Foundation First

  • In V1, timeline constraints kept the build on Node 16 instead of modern Node LTS tooling.
  • Player Pass launched on an early V1 baseline, requiring custom patches across design and logic.
  • Sequencing the foundation first prevents repeating that maintenance burden in V2.
2 · Why Sequence with Vue 3

shadcn-vue + Reka UI

  • Vue 3 unlocks shadcn-vue, which runs on Reka UI headless primitives.
  • Keyboard navigation, focus traps, and ARIA roles come built in.
  • Sequencing PDP, Cart, and Checkout behind Vue 3 lets us build once on modern primitives.
3 · V2 Token Fit

Already Built on Tailwind Base

  • Our Sept 9 V2 proposal (WEB-16658) already sits on a Tailwind base layer.
  • Our 68 semantic colour roles use explicit fill and on-colour pairs.
  • Those pairs map 1-to-1 into a shadcn-vue editable preset per brand.
Roadmap Alignment: Full UX page redesigns (PDP, Cart, Checkout) and the V2 token rollout are sequenced with the Vue 3 upgrade so Engineering and Design build once on shadcn-vue and Reka UI.
Sources: WEB-16658 (9 Sept 2026), V2 Role Vocabulary & Lab Mapping (14 Sept 2026). Contrast verified AAA (18.26:1 white on #151515).

03 · Commerce & Multi-Brand Extensions What We Add to Tailwind @theme Beside shadcn-vue

Store Roles That Sit Beside the Base Preset

Because shadcn-vue registers tokens in Tailwind CSS variables, our commerce roles slot right beside the standard preset inside the same Supernova exporter pipeline.

Commerce Actions & Badges

Cart, Sale, Loyalty, Stock

  • Add to Cart: action.cart.default (#0348CF) and action.cart.hover (#0341ba) stay distinct from general primary buttons.
  • Sale Pricing: sale.bg and sale.text (#9d0f34) plus proposed text.on-sale pair.
  • Goal Club Loyalty: loyalty.bg (#f0eee7), loyalty.text (#837139), and loyalty.icon.
  • Inventory Pills: stock.in, stock.backorder, and stock.out.
Typography & Elevation

Fluid Clamp & 4 Shadow Steps

  • Store Fonts: Figtree on Soccer.com, Chakra Petch + Inter on WorldSoccerShop, Roboto Condensed on 431 Sports.
  • Fluid Scale: 6 semantic type roles using CSS clamp() so headings scale smoothly without breakpoint jumps.
  • Elevation: Cut from 14 unused template shadows down to 4 named steps: raised, lifted, overlay, and pop.
Shared Motion & Campaign Layer

9 Motion Intents + 5 Campaign Roles

  • One Shared Motion Set: 9 semantic intents (press, hover, focus, reveal, dismiss, story) with reduced-motion handled at the token level once.
  • Campaign Layer Stays Separate: Seasonal Fastr blocks use the 5-role --campaign-* block (surface, primary, on-primary, headline, body) so short-lived sales never pollute Cabana.
Source: 004_Design-System/proposals/v2-role-vocabulary--draft-2026-09-09.md and 2026-10-17 Cabana vs. Campaign Tokens explainer.

Roadmap Sequence

Three Phased Tracks

  • 1. Ready Now (Zero Dev Time): Holiday campaign assets, paid media, emails, and Fastr CMS sandwich blocks ship immediately using existing V1 page tokens plus scoped campaign blocks.
  • 2. Sequenced with Vue 3: Adopt shadcn-vue and Reka UI with built-in accessibility and our 68-role V2 token preset across Soccer.com, WorldSoccerShop, and 431 Sports.
  • 3. Core UX Page Redesigns: Build PDP, Cart, and Checkout once on Vue 3 + shadcn-vue + V2 tokens to avoid duplicate engineering work.
